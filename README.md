# CaseChamp

В GUI для учётной записи **admin** аватар в боковой панели не отображается (только инициал и отдельный цвет имени).

## Text2SQL через Mistral

В CLI можно писать запросы на русском языке, а Mistral будет переводить их в SQL:

```text
\ai покажи имена всех пользователей старше 25 лет
```

Если в описании задачи не хватает таблицы, колонки, условия, периода или другого обязательного параметра, модель должна вернуть сообщение вида:

```text
Отсутствует информация о ...
```

### Настройка API-ключа

Для работы Text2SQL нужен личный API-ключ Mistral. Его можно получить на сайте Mistral AI:

1. Откройте сайт Mistral AI: https://mistral.ai/.
2. Перейдите в раздел для разработчиков / La Plateforme: https://console.mistral.ai/.
3. Зарегистрируйтесь или войдите в аккаунт.
4. В личном кабинете найдите раздел API keys и создайте новый ключ.
5. Скопируйте ключ один раз после создания.
6. В корне проекта создайте файл `mistral_api_key`.
7. Положите в него ключ одной строкой, без кавычек.

Файл `mistral_api_key` добавлен в `.gitignore`, поэтому он не должен попадать в репозиторий.

Если файла нет, при первом запуске `dbcli` создаст его автоматически с placeholder-строкой. После этого замените placeholder на настоящий ключ.

Также можно использовать переменные окружения:

```bash
export MISTRAL_API_KEY="your-api-key"
export MISTRAL_MODEL="mistral-small-latest"
```

или указать путь к файлу с ключом:

```bash
export MISTRAL_API_KEY_FILE="/path/to/mistral_api_key"
```

Не используйте один общий ключ для всех пользователей. Каждый пользователь должен создать свой ключ Mistral, иначе общий ключ можно украсть, исчерпать лимиты или заблокировать.
