Положите сюда файлы релизов:

  topiteneninglmsabce-windows.exe   — клиент для Windows
  topiteneninglmsabce-linux         — клиент для Linux (chmod +x)

После добавления файлов кнопки «Скачать» на сайте активируются автоматически
(при открытии сайта через HTTP, не file://).

Альтернатива: выложите релизы в GitHub Releases и замените href в index.html
на прямые ссылки вида:
  https://github.com/USER/REPO/releases/download/v1.0.0/...
