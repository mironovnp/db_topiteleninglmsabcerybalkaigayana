О проекте

topiteneninglmsabce_и_гаяна — учебная система управления базами данных с десктопным клиентом, консольным интерфейсом и поддержкой Text2SQL через Mistral AI.

Подробное описание проекта будет добавлено позже. Здесь появится информация о возможностях, архитектуре и сценариях использования.

Компоненты

  • Движок СУБД на C++ (хранение, индексы, WAL, выполнение SQL)
  • Сервер dbserver с HTTP API
  • CLI dbcli с командой \ai для запросов на русском языке
  • Графический клиент для Windows и Linux

Для Text2SQL настройте API-ключ Mistral — см. вкладку Mistral API.

Регистрация в Mistral и получение API-ключа

Для функции Text2SQL (перевод запросов с русского в SQL) каждому пользователю нужен личный API-ключ Mistral. Ниже — пошаговая инструкция.

Важно: не публикуйте ключ в Git, на скриншотах и в общих чатах. Используйте свой ключ; общий ключ могут украсть или исчерпать лимиты.
1

Откройте сайт Mistral AI

Перейдите на официальный сайт:

mistral.ai ↗
2

Откройте консоль разработчика

La Plateforme — личный кабинет для API:

console.mistral.ai ↗
3

Зарегистрируйтесь или войдите

Используйте email или способ входа, который предложит сайт (Google, GitHub и т.д.).

4

Откройте раздел API keys

В боковом меню найдите пункт API keys (или Workspace → API keys).

5

Создайте новый ключ

Нажмите Create new key / Add API key, задайте имя (например topiteneninglmsabce).

6

Скопируйте ключ

Ключ показывают один раз — сразу сохраните его в надёжное место. На скриншотах для сайта используйте замазанный ключ.

7

Укажите ключ в проекте

Один из способов:

  1. Файл mistral_api_key в корне проекта (одна строка, без кавычек)
  2. Переменная окружения: export MISTRAL_API_KEY="ваш-ключ"
  3. В графическом клиенте: Настройки → Mistral — вставить и сохранить
Файл mistral_api_key указан в .gitignore — не коммитьте его в репозиторий.
